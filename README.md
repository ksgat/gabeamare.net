## details

- the landing page is an electric-blue panel grid set in PP Neue Montreal.
- GitHub and Hackatime activity are glsl shaders
- the loading field is a canvas-rendered Legendre-symbol visualization of `x² + y² − t` over `F₅₉`
- I did design and then code was oai codex (have mercy pls im a chud)

## run it

```bash
npm install
npm run dev
```

then pull up [localhost:3000](http://localhost:3000).
